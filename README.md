# 剧集烧录字幕去片头片尾工具集
流程：将字幕烧录到视频文件→切除片头片尾→合并文件
得到一个所有剧集的无片头片尾集合视频。
本工具集包含多种用于批量处理剧集视频文件的 Bash 脚本，支持字幕烧录、片头片尾裁剪、视频合并等常见需求。所有脚本均需依赖 ffmpeg，部分脚本还需 HandBrakeCLI。

## 脚本列表与功能说明

### 1. brake.sh
- **功能**：使用 Apple Silicon 的 VideotoolBox 硬件加速，将当前目录下 01c.mkv ~ 26c.mkv 的字幕（第2轨）烧录进视频，并输出为 01.mp4 ~ 26.mp4。
- **用法**：直接运行脚本，无需参数。自动批量处理。
- **依赖**：ffmpeg（需支持 videotoolbox）

### 2. cut82send.sh
- **功能**：批量裁剪当前目录下所有视频（mp4/mkv/mov/avi），去除每个视频最后 82 秒内容，安全处理浮点时长。
- **用法**：直接运行脚本，无需参数。输出为原文件名加 _trim82 后缀。
- **依赖**：ffmpeg, ffprobe, awk

### 3. cut90s.sh
- **功能**：批量裁剪当前目录下所有视频（mp4/mkv/mov/avi），去除每个视频前 90 秒内容（不转码，快速）。
- **用法**：直接运行脚本，无需参数。输出为原文件名加 _cut90 后缀。
- **依赖**：ffmpeg

### 4. cutbegin.sh
- **功能**：交互式裁剪单个视频文件的片头（指定时长），保留后面内容。
- **用法**：`./cutbegin.sh 输入视频文件`
  - 按提示输入要裁剪的片头时长（格式 mm:ss 或 hh:mm:ss）。
  - 输出为原文件名加 _trimmed_start 后缀。
- **依赖**：ffmpeg

### 5. cutend.sh
- **功能**：交互式裁剪单个视频文件的片尾（指定时间点），保留前面内容。
- **用法**：`./cutend.sh 输入视频文件`
  - 按提示输入要保留的截止时间点（格式 mm:ss 或 hh:mm:ss）。
  - 输出为原文件名加 _trimmed 后缀。
- **依赖**：ffmpeg

### 6. hbrake.sh
- **功能**：使用 HandBrakeCLI 将 MKV 文件中的字幕烧录进视频并转为 MP4。
- **用法**：`./hbrake.sh 输入文件.mkv`
  - 输出为原文件名加 _burned.mp4。
- **依赖**：HandBrakeCLI（需提前安装，macOS 可用 `brew install handbrake`）

### 7. join.sh
- **功能**：交互式合并当前目录下多个视频文件（mp4/mkv/avi/mov），按数字顺序排列，支持手动选择合并文件。
- **用法**：直接运行脚本，按提示选择要合并的文件（可输入范围如 1-26）。
- **依赖**：ffmpeg

---

## 通用说明

- 所有脚本建议在 macOS/Linux 下运行，需提前安装 ffmpeg。
- 批量脚本默认处理当前目录下所有符合条件的文件，输出文件不会覆盖原文件。
- 如遇权限问题，请先赋予脚本可执行权限：`chmod +x 脚本名.sh`
- 建议先备份原始视频文件。
